# ClearMed

ClearMed is an AI-powered medical report explainer that:
- Accepts PDF/JPG/JPEG/PNG medical reports
- Extracts structured test results
- Highlights HIGH / LOW / NORMAL / UNKNOWN values
- Produces a simple-language explanation
- Supports English, Tamil, and Hindi
- Generates a voice explanation
- Stores report metadata in MongoDB

## 1. Required software

Install these on the new laptop:

### Python
Recommended: Python 3.11.x

Check:
```powershell
python --version
```

### Node.js
Install a current Node.js LTS release.

Check:
```powershell
node --version
npm --version
```

### MongoDB
Choose ONE:

Option A — MongoDB Atlas (recommended for team use)
- Create/use a MongoDB Atlas cluster
- Put the MongoDB connection string in the backend `.env`

Option B — MongoDB Community Server
- Install MongoDB locally
- Make sure MongoDB is running before starting FastAPI
- If using the current local configuration, the backend may use:
  mongodb://127.0.0.1:27017

### Git (optional)
Git is not required if you are transferring the project as a ZIP.

## 2. Services that do NOT need to be installed locally

These are hosted services used by ClearMed:
- SNS Agent Workbench
- Groq API
- Sarvam TTS

The laptop only needs the required API configuration in `.env`. Do not install SNS Workbench locally.

## 4. Backend setup

Open PowerShell in the backend folder:

```powershell
cd "C:\ClearMed\clearmed-backend"
```

Create the virtual environment:

```powershell
python -m venv .venv
```

Activate it:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install backend packages:

```powershell
python -m pip install -r requirements.txt
```

## 5. Backend environment variables

Create:

```text
clearmed-backend\.env
```

Example:

```env
MONGODB_URI=YOUR_MONGODB_CONNECTION_STRING
GROQ_API_KEY=YOUR_GROQ_API_KEY
GROQ_MODEL=llama-3.3-70b-versatile
```

Do NOT commit or publicly share `.env`.

The current hosted SNS workflow is configured in the backend code:

```text
https://api.agents.snsihub.ai/webhook/testing
```

If the SNS production URL changes later, update the backend configuration accordingly.

## 7. Frontend setup

Open a SECOND PowerShell window:

```powershell

```

```powershell

Open:

```

## 12. Common problems

### Python command not found
Install Python 3.11 and reopen PowerShell.

### npm command not found
Install Node.js LTS and reopen PowerShell.

### `/db-test` fails
Check that MongoDB is running or that the Atlas connection string is correct.

### Groq 401/403
Check that `GROQ_API_KEY` is valid and that the Groq account has access.

### Groq 429/5xx
Retry later; the backend returns a clear rate-limit or service-unavailable error.

### Frontend says FastAPI disconnected
Make sure the backend is running on:
```text
http://127.0.0.1:8000
```

### Voice player shows 0:00
Make sure the backend is running and the `/audio/...` endpoint is reachable.

## 13. Recommended teammate setup

For the easiest team setup, use MongoDB Atlas instead of local MongoDB. Then each laptop can use the same Atlas cluster without installing and running MongoDB locally.
